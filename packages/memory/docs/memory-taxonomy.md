### Memory Taxonomy

- `WORKING`: transient execution context and temporary reasoning variables.
- `SHORT_TERM`: recent interactions with configurable expiration.
- `LONG_TERM`: durable preferences, approved facts, goals, and learned behavior.
- `EPISODIC`: event-based experiences with participants, outcomes, and context.
- `SEMANTIC`: concepts, definitions, domain facts, and relationships.
- `PROCEDURAL`: reusable patterns, routines, and successful workflows.
- `CONVERSATION`: topic continuity, references, decisions, and follow-up context.
- `PROJECT`: milestones, requirements, tasks, architecture notes, and history.
- `WORKSPACE`: active workspace state, objectives, and preferences.
- `AGENT`: isolated memory spaces per specialized agent.

### Metadata Baseline

- Every memory carries: identifier, created/updated timestamps, confidence, importance, source, visibility, privacy level, relationships, classification, tags, and version.
- Extended tracking includes lineage, access frequency, feedback signal, optional retention lock, and expiration.
